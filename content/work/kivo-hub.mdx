Kivo Hub is a personal productivity dashboard that unifies everyday life management into a single, clean interface. Instead of switching between separate apps for tasks, expenses, and wishlists, users get one cohesive workspace.

## The Problem

Personal productivity often fragments across multiple apps — a to-do list here, an expense tracker there, a wishlist somewhere else. Context switching between tools adds friction and makes it harder to maintain habits.

## Approach

Kivo Hub combines tasks, expense tracking, wishlist management, and activity logging into a unified React application. The interface prioritizes clarity and quick access, with each module sharing a consistent design language built with TypeScript and Tailwind CSS.

## What I Worked On

- Designed and built a unified dashboard layout connecting multiple productivity modules.
- Implemented task management with status tracking and prioritization.
- Built expense tracking with categorization and summary views.
- Added wishlist management and activity logging for a complete personal workspace.

## Outcome

Kivo Hub demonstrates how a thoughtfully designed single-page application can replace multiple disconnected tools, giving users a calmer, more focused productivity experience.
